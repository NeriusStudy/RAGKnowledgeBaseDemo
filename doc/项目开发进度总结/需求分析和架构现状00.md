## 二、核心需求分析

### 2.1 VectorDB 向量数据库

**功能需求**：
- **输入**：Document类或Document列表（已切分好的文档）
- **存储索引**：Document.metadata中的md5作为唯一标识
- **核心功能**：
  1. 向量存储：将文档转换为向量并持久化存储
  2. 向量检索：基于语义相似度检索文档，可自定义检索数量k
  3. 文档增删：支持单个和批量操作
- **技术实现**：
  - 嵌入模型：可自定义embedding model（需配置APIKEY）
  - 持久化方案：Chroma本地存储
  - 当前设计：基于LangChain的DashScopeEmbeddings + Chroma

**配置参数**：
- `EMBEDDING_MODEL_NAME = "text-embedding-2"`
- `VECTOR_SEARCH_DEFAULT_K = 10`
- `VECTOR_DB_PATH = "vector_db"`

---

### 2.2 KeywordDB 关键词数据库

**功能需求**：
- **输入**：Document类或Document列表（已切分好的文档）
- **存储索引**：Document.metadata中的md5作为唯一标识
- **核心功能**：
  1. 关键词存储：提取文档关键词并持久化
  2. 关键词检索：基于BM25算法进行关键词匹配检索，可自定义k
  3. 文档增删：支持单个和批量操作
- **技术实现**：
  - 检索算法：BM25（Best Matching 25）
  - 持久化方案：本地存储
  - 当前设计：基于LangChain的BM25Retriever

**配置参数**：
- `KEYWORD_SEARCH_DEFAULT_K = 10`
- `KEYWORD_DB_PATH = "keyword_db"`

---

### 2.3 Reranker 重排器

**功能需求**：
- **使用场景**：混合检索（Hybrid Search）后的结果重排序
- **核心功能**：
  1. RRF融合：对向量检索和关键词检索结果进行Reciprocal Rank Fusion
  2. 模型重排：使用重排序模型对融合结果进行精排
- **技术实现**：
  - 重排模型：可自定义rerank model（需配置APIKEY）
  - 当前设计：基于LangChain的DashScopeRerank

**配置参数**：
- `RERANK_MODEL_NAME = "gte-reranker"`
- `RRF_REFUSION_K = 20`（RRF融合时的候选文档数）
- `RERANK_K = 10`（最终返回的文档数）

---

### 2.4 RAGService RAG服务类

**依赖关系**：VectorDB + KeywordDB + Reranker

**核心功能**：

#### 2.4.1 文档管理
- **添加文档**：
  - 接收Document类（metadata中包含md5索引）
  - 同时存入VectorDB和KeywordDB
  - 支持单个和批量操作
- **删除文档**：
  - 根据md5索引
  - 同时从VectorDB和KeywordDB删除
  - 支持单个和批量操作

#### 2.4.2 检索功能
统一接口：`search(query: str, k: int, mod: str)`

**三种检索模式**：
1. **向量检索（mod="vector"）**：
   - 仅使用VectorDB进行语义检索
   - 适合语义理解类问题
   
2. **关键词检索（mod="keyword"）**：
   - 仅使用KeywordDB进行关键词匹配
   - 适合精确匹配类问题
   
3. **混合检索（mod="hybrid"，默认）**：
   - 并行调用VectorDB和KeywordDB
   - 使用Reranker进行RRF融合
   - 使用重排模型进行精排
   - 返回top-k结果

**配置参数**：
- `HYBRID_SEARCH_DEFAULT_K = 10`
- `RAG_SEARCH_DEFAULT_K = 10`

## 七、关键技术点

### 7.1 RRF融合算法

参考qaagent67lambda实现：

```python
def _weighted_rrf_fuse(path_results, weights, k=60):
    scores = defaultdict(float)
    for path_name, results in path_results.items():
        w = weights.get(path_name, 0.5)
        for rank, r in enumerate(results):
            key = f"{r['source']}#{r['chunk_id']}"
            scores[key] += w / (k + rank + 1)
    return sorted(scores.items(), key=lambda x: -x[1])
```
