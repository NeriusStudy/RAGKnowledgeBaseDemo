## 📊 项目概览

### 项目目标
实现一个基于 RAG（Retrieval-Augmented Generation）的知识库管理系统，支持多模态检索（向量检索、关键词检索、混合检索），为 AI 应用提供高质量的知识检索服务。

### 技术栈
- **框架**：LangChain
- **向量数据库**：Chroma
- **嵌入模型**：DashScope text-embedding-v2（阿里云）
- **重排序模型**：DashScope qwen3-rerank（阿里云）
- **关键词检索**：BM25 算法 + jieba 中文分词
- **编程语言**：Python 3.x
- **依赖库**：langchain, langchain-chroma, dashscope, rank_bm25, jieba

### 3. Reranker（重排序器）

**文件位置**：`Reranker.py`

**功能描述**：
混合检索的重排序器，使用 RRF 算法融合向量和关键词检索结果，并使用深度学习模型进行精确排序。

**核心方法**：

| 方法名 | 功能 | 参数 | 返回值 |
|--------|------|------|--------|
| `__init__()` | 初始化重排序器 | rerank_model_name | - |
| `rerank()` | 两阶段重排序 | query, vector_docs, keyword_docs, weights, k | List[Document] |
| `_rrf_fusion()` | RRF 融合算法 | vector_docs, keyword_docs, weights, k | List[Document] |
| `get_rerank_model_name()` | 获取模型名称 | - | str |

**技术实现**：

**阶段一：RRF 融合**
```python
def _rrf_fusion(self, vector_docs, keyword_docs, weights, k):
    # RRF 算法：score = w1/(k+rank1) + w2/(k+rank2)
    doc_scores = 
    
    # 向量检索打分
    for rank, doc in enumerate(vector_docs):
        md5 = doc.metadata.get('md5')
        doc_scores[md5] = weights['vector'] / (k + rank)
    
    # 关键词检索打分
    for rank, doc in enumerate(keyword_docs):
        md5 = doc.metadata.get('md5')
        if md5 in doc_scores:
            doc_scores[md5] += weights['keyword'] / (k + rank)
        else:
            doc_scores[md5] = weights['keyword'] / (k + rank)
    
    # 按分数排序
    sorted_docs = sorted(doc_scores.items(), key=lambda x: x[1], reverse=True)
    return sorted_docs[:k]
```

**阶段二：DashScope Rerank**
```python
# 使用 dashscope SDK 直接调用
import dashscope

# 配置工作空间
workspace_id = os.getenv('DASHSCOPE_WORKSPACE_ID')
if workspace_id:
    dashscope.base_http_api_url = f'https://{workspace_id}.cn-beijing.maas.aliyuncs.com/api/v1'

# 调用 Rerank API
response = dashscope.TextReRank.call(
    model=self.rerank_model_name,
    query=query,
    documents=[doc.page_content for doc in rrf_docs],
    top_n=k,
    return_documents=True
)

# 添加 rerank_score 到 metadata
for item in response.output.results:
    doc.metadata['rerank_score'] = item.relevance_score
```

**降级策略**：
```
Rerank API 成功 → 返回精排结果
    ↓ 失败
RRF 融合结果 → 返回粗排结果
    ↓ 失败
向量检索结果 → 返回基础结果
```

**测试结果**：
- ✅ RRF 融合算法正常工作
- ✅ DashScope Rerank API 调用成功
- ✅ 不同权重配置返回不同结果
- ✅ 降级策略正常工作

### 4. RAGService（RAG 统一服务）

**文件位置**：`RAGService.py`

**功能描述**：
整合 VectorDB、KeywordDB、Reranker 三大组件，提供统一的文档管理和检索接口。

**核心方法**：

| 方法名 | 功能 | 参数 | 返回值 |
|--------|------|------|--------|
| `__init__()` | 初始化 RAG 服务 | RAG_store_path, embedding_model_name, rerank_model_name | - |
| `add_document()` | 添加单个文档 | document: Document | bool |
| `add_documents()` | 批量添加文档 | documents: List[Document] | bool |
| `delete_document()` | 删除单个文档 | md5: str | bool |
| `delete_documents()` | 批量删除文档 | md5_list: List[str] | bool |
| `_vector_search()` | 向量检索（内部） | query: str, k: int | List[Document] |
| `_keyword_search()` | 关键词检索（内部） | query: str, k: int | List[Document] |
| `_hybrid_search()` | 混合检索（内部） | query, k, weights | List[Document] |
| `search()` | 统一检索接口 | query, mod, k, weights | List[Document] |
| `delete_me()` | 清理所有数据 | - | - |
| `get_embedding_model_name()` | 获取嵌入模型 | - | str |
| `get_rerank_model_name()` | 获取重排模型 | - | str |

**架构设计**：
```
RAGService
├── VectorDB (向量检索)
│   ├── DashScopeEmbeddings (text-embedding-v2)
│   └── Chroma (向量存储)
├── KeywordDB (关键词检索)
│   ├── BM25Retriever (BM25 算法)
│   └── jieba (中文分词)
└── Reranker (重排序)
    ├── RRF 融合
    └── DashScope Rerank (qwen3-rerank)
```

**三种检索模式**：

1. **vector 模式**（语义检索）
```python
def _vector_search(self, query, k):
    return self.vector_db.search(query, k)
```

2. **keyword 模式**（精确匹配）
```python
def _keyword_search(self, query, k):
    return self.keyword_db.search(query, k)
```

3. **hybrid 模式**（混合检索，推荐）
```python
def _hybrid_search(self, query, k, vector_weight, keyword_weight):
    # 步骤1：向量检索
    vector_results = self.vector_db.search(query, k * 2)
    
    # 步骤2：关键词检索
    keyword_results = self.keyword_db.search(query, k * 2)
    
    # 步骤3：重排序（RRF + Rerank）
    weights = {'vector': vector_weight, 'keyword': keyword_weight}
    results = self.reranker.rerank(query, vector_results, keyword_results, weights, k)
    
    return results
```

**数据一致性保证**：
```python
def add_document(self, document):
    # 添加到向量库
    if not self.vector_db.add_document(document):
        return False
    
    # 添加到关键词库
    if not self.keyword_db.add_document(document):
        # 回滚向量库
        md5 = document.metadata.get('md5')
        self.vector_db.delete_document(md5)
        return False
    
    return True
```

**测试结果**：
- ✅ 三种检索模式全部正常工作
- ✅ 向量检索返回语义相关文档
- ✅ 关键词检索返回精确匹配文档
- ✅ 混合检索返回最优结果（带 rerank_score）
- ✅ 不同权重配置影响结果排序
- ✅ 数据一致性保证机制正常
- ✅ 降级策略正常工作

## 🔧 技术难点和解决方案

### 难点 1：Chroma 导入弃用警告
**问题**：`LangChainDeprecationWarning: The class Chroma was deprecated in LangChain 0.2.9`  
**解决**：改用 `from langchain_chroma import Chroma`  
**影响**：需要安装 `pip install langchain-chroma`

### 难点 2：DashScope 模型名称错误
**问题**：`Model not exist: text-embedding-2`  
**解决**：使用正确的模型名 `text-embedding-v2`  
**影响**：需要更新 config.py

### 难点 3：BM25Retriever API 变化
**问题**：`'BM25Retriever' object has no attribute 'get_relevant_documents'`  
**解决**：添加版本兼容代码，优先使用 `invoke()`  
**代码**：
```python
try:
    results = self._retriever.invoke(query)
except AttributeError:
    results = self._retriever.get_relevant_documents(query)
```

### 难点 4：DashScope Rerank 工作空间配置
**问题**：LangChain 的 DashScopeRerank 不支持工作空间 ID  
**解决**：改用 dashscope SDK 直接调用  
**代码**：
```python
import dashscope
workspace_id = os.getenv('DASHSCOPE_WORKSPACE_ID')
if workspace_id:
    dashscope.base_http_api_url = f'https://{workspace_id}.cn-beijing.maas.aliyuncs.com/api/v1'
```

### 难点 5：数据一致性保证
**问题**：添加文档时，如何保证 VectorDB 和 KeywordDB 的数据一致性  
**解决**：添加回滚机制  
**代码**：
```python
if not self.vector_db.add_document(document):
    return False
if not self.keyword_db.add_document(document):
    self.vector_db.delete_document(md5)  # 回滚
    return False
```
