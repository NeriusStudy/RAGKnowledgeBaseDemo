# 环境变量配置说明

## 必需的环境变量

### 1. DASHSCOPE_API_KEY
阿里云 DashScope API 密钥

**设置方法：**

**Windows (cmd):**
```bash
set DASHSCOPE_API_KEY=your_api_key_here
```

**Windows (PowerShell):**
```powershell
$env:DASHSCOPE_API_KEY="your_api_key_here"
```

**Linux/Mac:**
```bash
export DASHSCOPE_API_KEY="your_api_key_here"
```

### 2. DASHSCOPE_WORKSPACE_ID (可选)
阿里云工作空间 ID，如果你的 API Key 绑定了特定工作空间，需要设置此变量

**从你的 test_rerank_model.py 来看，你的工作空间 ID 是：**
```
llm-fq43z9u2tnoy3m7o
```

**设置方法：**

**Windows (cmd):**
```bash
set DASHSCOPE_WORKSPACE_ID=llm-fq43z9u2tnoy3m7o
```

**Windows (PowerShell):**
```powershell
$env:DASHSCOPE_WORKSPACE_ID="llm-fq43z9u2tnoy3m7o"
```

**Linux/Mac:**
```bash
export DASHSCOPE_WORKSPACE_ID="llm-fq43z9u2tnoy3m7o"
```

## 完整设置示例

**Windows (cmd) - 一次性设置两个变量：**
```bash
set DASHSCOPE_API_KEY=your_api_key_here
set DASHSCOPE_WORKSPACE_ID=llm-fq43z9u2tnoy3m7o
```

**Windows (PowerShell):**
```powershell
$env:DASHSCOPE_API_KEY="your_api_key_here"
$env:DASHSCOPE_WORKSPACE_ID="llm-fq43z9u2tnoy3m7o"
```

## 验证环境变量

**Windows (cmd):**
```bash
echo %DASHSCOPE_API_KEY%
echo %DASHSCOPE_WORKSPACE_ID%
```

**Windows (PowerShell):**
```powershell
echo $env:DASHSCOPE_API_KEY
echo $env:DASHSCOPE_WORKSPACE_ID
```

**Linux/Mac:**
```bash
echo $DASHSCOPE_API_KEY
echo $DASHSCOPE_WORKSPACE_ID
```

## 运行测试

设置环境变量后，在同一命令行窗口中运行测试：

```bash
cd F:\SE_works\application\dify\RAGKnowledgeBaseDemo-main\RAGKnowledgeBaseDemo-main\test_scripts

# 检查 API Key
python check_api_key.py

# 测试 Rerank 模型（单独测试）
python test_rerank_model.py

# 完整的 Reranker 测试
python test_reranker.py
```

## 注意事项

1. **环境变量的作用域**：在 cmd 或 PowerShell 中使用 `set` 或 `$env:` 设置的环境变量只在当前窗口有效，关闭窗口后失效
2. **永久设置**：如需永久设置，可以在 Windows 系统环境变量中配置
3. **Python 进程**：环境变量必须在启动 Python 进程之前设置好
4. **工作空间 ID**：如果你的 test_rerank_model.py 工作正常，说明需要设置工作空间 ID
